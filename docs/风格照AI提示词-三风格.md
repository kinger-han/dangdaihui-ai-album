# 风格照提示词（三风格 · 直用版）

> 用法：后台将拍照原图作为输入图，把对应风格的提示词作为 prompt 一起送给大模型即可。每段自包含，无需额外拼接。
> 框策略：光影焕新 → AI 生成大会风格纪念框；水墨国风 → AI 生成轻细中式画框；手绘插画 → 不带框（纯插画画面）。
> 统一铁律：
> 1. 所有框内**禁止生成文字**（AI 文字必错）；装饰用通用图标/描边元素（金星、麦穗、祥云、对称线条等）；
> 2. **不出现规范化标志**：禁止党徽、国徽、旗帜等规范化标志（AI 画这类标准标志必歪，属政治性事故，必须用官方标准素材，不进入 AI 出图）；装饰点缀用通用元素即可：五角星、麦穗、祥云、对称细线等非规范化装饰；
> 3. 框与装饰保持简洁，复杂花纹与大面积装饰是 AI 不稳的重灾区。

---

## 1. 光影焕新（自然美颜 + 大会纪念框）

```
请基于我提供的照片原图，对人物进行自然、克制的智能美化，并在照片四周生成一个简洁庄重的大会纪念框，输出一张带框的「光影焕新」风格纪念照：
1. 人脸特征必须完全保留——脸型、五官、骨相、肤色、脸上的雀斑痣点等都与原图一致，禁止换脸，禁止过度美白（不要改变肤色深浅）；
2. 只做轻度美化：淡化临时瑕疵（痘印、泛红、暗沉、黑眼圈），均匀肤色，去除脸上油光，但必须保留毛孔和真实皮肤纹理，不要磨皮、不要塑料感、不要假面感；
3. 适度提亮整体画面，柔和高光避免过曝，降低暗部死黑，画面通透、干净、精神、自然；
4. 纪念框要求：简洁的金色细线框，线条匀称笔直，框内四角或上下边可用金色五角星、对称细线等通用装饰做少量点缀，整体庄重大气、与大会氛围相符；边框干净工整，点缀少量精致，不要复杂花纹和大面积装饰，不要任何变形或扭曲；
5. 框内及画面上禁止出现任何文字、字母；禁止出现党徽、国徽、旗帜等规范化标志元素；
6. 背景内容不变，只做光线与色调的轻微调整；人物姿态、服装、构图不变；照片周围留出适度空白以容纳边框。
```

> 若生图接口支持负面提示词，建议附加：`扭曲边框, 斜框, 缺角, 断线, 文字, 字母, 党徽, 国徽, 旗帜, 塑料感皮肤, 过度磨皮, 假白假面, 蜡像感`（英文：distorted frame, broken lines, text, letters, party emblem, national emblem, flag, plastic skin, airbrushed, fake whitening）

## 2. 水墨国风（水墨背景 + 轻细中式画框）

```
请基于我提供的照片原图，生成一张「水墨国风」风格的带框纪念照：
1. 人物主体保留写实风格，人脸五官、表情、姿态、服装必须与原图完全一致，不要重绘面部；
2. 将背景处理为写意水墨风格——水墨晕染、远山云雾、留白意境，主色调为墨色，可少量点缀朱砂红；人物与水墨背景之间过渡自然柔和；
3. 在照片四周生成一个轻细的中式画框：细金线或细朱砂线描边，线条匀称笔直、简洁素雅，与水墨画面融为一体，不要厚重的红底或大面积装饰；
4. 框上点缀少量即可：祥云线条、对称细线等，干净工整，不要复杂花纹，不要任何变形或扭曲；
5. 框内及画面上禁止出现任何文字、印章、字母；禁止出现党徽、国徽、旗帜等规范化标志元素；
6. 整体素雅、庄重、有东方韵味，照片周围留出适度空白以容纳边框。
```

> 若生图接口支持负面提示词，建议附加：`扭曲边框, 斜框, 缺角, 断线, 文字, 印章, 字母, 党徽, 国徽, 旗帜, 动漫, 厚重红框`（英文：distorted frame, broken lines, text, seal, stamps, party emblem, national emblem, flag, anime, heavy red frame）

## 3. 手绘插画（纯插画画面，不带框）

```
请基于我提供的照片原图，生成一张「手绘插画」风格纪念照，画面不带任何相框：
1. 整体为清新细腻的水彩插画质感，笔触柔和、色彩淡雅；
2. 人物做轻度插画化处理，但五官轮廓清晰、可以清楚辨认、脸部特征与原图一致；
3. 背景简化为干净明亮的插画场景，可以有浅色晕染和留白；画面轻松、有艺术感；
4. 画面四边保持干净的插画边缘，不要任何边框、描边、装饰线；
5. 画面上禁止出现任何文字、字母；禁止出现党徽、国徽、旗帜等规范化标志元素。
```

> 若生图接口支持负面提示词，建议附加：`相框, 边框, 描边, 文字, 字母, 党徽, 国徽, 旗帜, 动漫二次元, 厚涂油画, 夸张变形`（英文：frame, border, outline, text, letters, party emblem, national emblem, flag, anime, heavy oil painting, exaggerated distortion）
