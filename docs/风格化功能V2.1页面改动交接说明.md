## 0. 一句话需求

经典纪念框**直出成品**之后，用户可对同一张照片做**可选**的“风格化”（光影焕新 / 水墨国风 / 手绘插画），结果**不单独做页面**——收进原照片详情页内做标签切换，保存/分享跟随当前标签。风格化作品是独立的新作品（新编号），只改 **H5 两个页面 + 后端少量字段/接口**。PC 端本轮已实现：详情弹窗同组合并展示 + 新增「画风管理」页（提示词可配置、可启用/禁用）。

全程用户界面**不出现“AI / 智能”字眼**。

## 1. 背景与已定决策（不要推翻）

| 决策点 | 结论 |
|---|---|
| 风格化形态 | 拍照后可选后处理，**不是模板**；模板=排版层、画风=图像风格层，正交不混排 |
| 入口 | 唯一入口 = 照片详情页标签行末尾的 `+ 换个风格`（轻量弹层选画风，卡内示例图+描述）；无独立页面、无新路由 |
| 作品模型 | 每个风格 = 一条**新 Work**（独立编号，全局流水号顺延如 `FJDH-0328-05`）；同底片可生成多个风格 |
| 编号 | 编号仅后台主键；界面显示 `水墨国风 · FJDH-0328-04`（风格名 + 作品编号），不显示“源自”标注（同页/同卡已表达关系） |
| 数据溯源 | Work 加 `style_id`（空=直出）+ `source_work_id`（指向来源原图作品） |
| 保存/分享 | 页面主操作区两个并列主按钮：`保存本地` / `分享上屏`（4字对4字）；作用于**当前选中标签**那张；各风格独立作品独立接口，走现有链路 |
| 保存交互 | 原型中 `保存本地` 点击即 toast「已保存」，**不做长按弹层效果**（原型示意图，不浪费时间做效果） |
| 生成并发 | 一次只跑一个风格任务；点击后卡位显示生成中（3 秒模拟），可离开页面后台继续；完成后标签行新增该风格 + “新”红点；拍照生成直出无过渡动画 |
| 失败 | toast 轻提示（不弹阻断弹窗），卡片恢复，原图始终可保存 |
| 降级 | 风格级故障 → `enabled` 热开关控制，置灰/隐藏；全关 → “+ 换个风格”入口隐藏，回到纯直出 |
| 文案 | 入口 `+ 换个风格`；风格卡“光影焕新·约10秒 / 水墨国风·约20秒 / 手绘插画·约25秒”；生成中卡位转圈；完成 toast“水墨国风已生成，可在标签与我的纪念查看”；失败“生成未完成，请稍后重试” |
| 画风大图表达 | 原型占位图用 CSS 滤镜示意画风差异（水墨=灰度、手绘=低饱和、光影=提亮亮度），**只做原型示意，不做真图** |
| 合规 | 风格化只改光影/环境/画风，不改人脸基本特征；文字层（大会名/编号/边框）合成不进生成模型；AI 初审补“风格合规 + 人脸一致性”两维 |

## 3. 移动端 H5 改动明细

### 3.1 照片详情页（08-result.html = H08）— 主改动

页面现状（原型 DOM 锚点）：大图 `.result-photo`（内含 `.photo-bg`、`.photo-person`）+ `.result-number` → `.r-tabs`（标签行）→ `.result-info`（模板名/提示）→ `.ra-actions`（两个并列主按钮）→ `.selection-box`（分享说明/勾选/查看展示说明）。结构如下：

```
大图（当前标签那张，3:4，带画风滤镜类 effect-<styleId>）
├─ 【标签行 .r-tabs】[原图] [水墨国风] (+ 换个风格)   ← 已有图平铺，默认选中原图
│    · 有展示状态的风格标签显示绿字“●展示中”
│    · 生成完成的新风格带红点“新”
│    · 生成中显示转圈占位
│    · 末尾 `+ 换个风格`（存在可生成画风时才显示）
├─ 作品信息： 模板名 + 第 328 号纪念档案 · FJDH-0328-01
│    （风格作品显示：水墨国风 · 源自 FJDH-0328-01）
├─ 操作区 .ra-actions：【保存本地】(primary) 【分享上屏】(sub 红描边)   ← 两个主按钮并排
│    · 保存本地 → toast「已保存」（不再弹长按弹层）
│    · 分享上屏 → 需先勾选下方授权；已提交/展示中按钮变“等待上屏/正在展示”并禁用
├─ “+ 换个风格”弹层（.st-mask + .st-sheet）：列出未生成的画风卡，点即发起生成
└─ 风采邀请区（.selection-box，仅未提交时显示：说明 + 勾选同意 + 查看展示说明）
```

**关键规则（实现必须遵守）**：
1. 标签行点选 → 大图**原地切换**（换 `effect-<styleId>` 滤镜类），无跳转；原图本地缓存，秒切。
2. `保存本地` / `分享上屏` → 以**当前标签作品**的 ID 执行；后端各风格是独立 Work，接口按各自 ID 走，**业务逻辑零改动**。
3. 切换标签时，`#result-number`、模板名、展示状态文案同步换成该作品的。
4. “+ 换个风格”弹层内容由 `STYLES` 数据驱动（enabled=false / 已全部生成 → 入口隐藏）。
5. 生成中离开页面（返回/去其他页）任务不中断（setTimeout 全局模拟）；回页后若已完成，标签行直接出现该风格。
6. 从“我的纪念”带风格作品进入 → 默认选中对应标签（renderResult 内 loadResultGroup 按 `state.curWork.no` 定位）。
7. 沉浸预览（点大图）显示当前标签大图（含滤镜）。

**数据获取**：进入本页时按 `state.curWork`（当前作品）拉同组列表——`loadResultGroup()`：root = `sourceWorkId` 为空的作品；组 = root + 所有 `sourceWorkId === root.no` 的风格作品；`state.curTabIdx` 为当前作品在组内下标。

**前端状态**：`state.curTabIdx`（当前标签）、`state.curGroup[]`（同组作品）、`state.generatingStyleId`（生成中的画风 id）。

### 3.2 我的纪念（10-mine.html = H10）

现状：`renderMine()` 遍历 `MY_WORKS` 渲染 `.mine-card`（缩略图 + 模板名 + 编号时间 + 状态 pill），点击 `openWorkByNo(no)` 进入 result 页。

**改动**：
1. **合并卡片**：`_mineGroups()` 按 `sourceWorkId` 归组（原图 + 其风格衍生）合并为一张卡：
   - 卡片主体 = 原图大封面（默认展示原图）；右下角 `✦N`（组内共 N 张，原本图+风格数）。
   - 封面下衍生缩略行 `.mine-derivs`：`[原图] [光影焕新] [水墨国风]`——组内有几张显示几张，不折叠；风格缩略带滤镜，展示中风格有绿色小圆点。
   - 无衍生作品卡片与现状完全一致。
2. **点击行为**：点卡片主体/原图缩略 → 打开原图详情（默认原图标签）；点风格缩略（`stopPropagation`）→ 进详情页并**默认选中对应标签**。
3. 风格作品在“我的纪念”缩略显示风格名小字，不加“AI”前缀。

### 3.3 其他 H5 页面

- H01/H03/H05/H07/H09/H11/H12：**不改**。
- 07-generating 生成直出作品仍无 `sourceWorkId`/`styleId`（默认直出），无需改。

## 4. 后端改动（P0）

| 改动 | 说明 |
|---|---|
| Work 加字段 | `style_id`（画风 ID；空 = 直出原图）、`source_work_id`（指向来源原图作品；直出为空）——一次迁移，历史数据两字段置空即直出 |
| 新对象 Style | 画风 ID、名称、示例图、预计耗时、`enabled`（热开关）、排序、提示词、生成数量 |
| `GET /styles` | 返回画风列表（id/名称/示例图/预计耗时/enabled）；H5 风格入口渲染 + 热开关/降级的**唯一数据源** |
| `POST /works` | 加可选 `style_id`：空 = 原直出逻辑；非空 = 创建风格化任务，**复用现有生成任务/审核/上屏链路**；编号逻辑不动（成功即按全局顺序取号）；同底片+同风格重复请求用幂等键防重 |
| `GET /works/{id}` / `GET /visitors/me/works` | 返回含 `style_id`、`source_work_id`；前端据此归组（列表可一次带出，前端合并展示） |
| 风格化结果图 | 文字层（大会名/编号/边框）在模型输出后**重绘合成**，不走生成模型（与原图一致的安全策略） |
| 失败记录 | 记录失败码与日志，供 B 端排查；失败不产生新编号 |

## 5. PC 端改动（本轮已实现）

### 5.1 照片详情弹窗（shell-pc.html，照片管理/上屏展示审核共用）— 同组合并展示

- **数据结构**：`window.__PHOTO_DETAILS[no]` 每条加 `sourceWorkId` / `styleId`；详情打开时 `pdBuildGroup(no)` 按来源组构建 `__pdGroup`（root + 全部以其为 source 的风格作品）。
- **弹窗布局**：`.pd-img` 大图下新增 `.pd-tabs` 标签行（`原图` / 画风名），点标签切大图（带 `effect-<styleId>` 滤镜类）+ 右侧字段跟随切换：
  - 公共字段（组级，不随切换）：模板、微信号、来源屏幕。
  - 当前作品字段（跟随标签）：画风（直出/画风名，金色标注）、上屏状态、创建时间、上屏展示时间、下屏时间。
  - 风格作品额外一行：`源自 <来源编号>`。
- 大图放大（pdZoomPhoto）跟随当前标签。
- 画风名解析走 `window.__STYLE_LIST`（各页面脚本有兜底初始化，shell 用 `||` 防覆盖）。

### 5.2 照片管理（01-photo-mgmt.html）

- `PHOTO_LIST` 新增 2 条风格衍生演示数据：`FJDH-0002-02`（水墨国风·等待上屏）、`FJDH-0002-03`（光影焕新·暂未分享），均 `sourceWorkId: 'FJDH-0002-01'`。
- 列表：原图行缩略右下角 `✦3` 角标；衍生行缩略带画风滤镜 + 模板列金色风格小标；`getTplBgIdx` 对衍生作品递归取原图背景。
- `buildPhotoDetails()` 带 `sourceWorkId`/`styleId`，衍生作品背景继承原图；`openPhotoDetail` 每次打开前重建（防被 02 页覆盖）。
- `batchDelete` 删除原图时连带删除其风格衍生。

### 5.3 上屏展示审核（02-selection-mgmt.html）

- `SEL_LIST` 新增衍生演示 `FJDH-0002-02`（水墨国风·等待上屏，on:false）；行渲染带滤镜+风格小标；`selBuildDetails` 带 `sourceWorkId`/`styleId`；`selTplBg` 递归原图。
- 共用 shell 的合并详情弹窗，无额外改动。

### 5.4 画风管理（04-style-mgmt.html，本轮新增）

- **菜单**：shell-pc `.sub-menu` 新增 `画风管理`（`switchPage('画风管理', this)`）。
- **列表字段**：示例（画风滤镜缩略图）、画风名称、预计耗时、生成数量、提示词（长文本）、状态（启用/禁用标签）、操作（编辑 / 启用|禁用）。
- **新增/编辑弹窗字段**：画风名称、预计耗时、状态（启用/禁用）、生成数量、提示词（textarea）。
- **交互**：启用/禁用即切即时生效；编辑保存同步到 `window.__STYLE_LIST`（与详情弹窗画风名共用数据源；移动端「换个风格」为各自 mock 数据，演示为纯前端联动）。
- 数据源：`window.__STYLE_LIST`（3 个画风：光影焕新 / 水墨国风 / 手绘插画，含 prompt/count/enabled）。

## 7. 验收清单（原型演示）

1. 保存一张纪念照 → 详情页出现标签行；默认标签 = 原图；两个主按钮 `保存本地 / 分享上屏` 并列可见（一屏内不用下拉）。
2. 点 `+ 换个风格` → 弹出未生成画风（光影焕新 / 手绘插画；水墨已生成则不出现）；选水墨国风 → 标签行出现转圈生成中；期间可返回/去我的纪念再回来，任务继续。
3. 约 3 秒后完成：标签行出现“水墨国风（新红点）”，“+ 换个风格”里不再有水墨；toast 提示；原地切换无跳转。
4. 点标签 → 大图原地切换（滤镜变化）；切换后保存/分享以该作品执行；界面编号/模板/状态文案随标签切换。

6. 点 `分享上屏` 未勾选授权 → toast「请先勾选同意展示授权」；勾选后提交 → 按钮变“等待上屏”禁用。
7. 点 `保存本地` → toast「已保存」，无弹层。
8. PC 照片管理：FJDH-0002-01 行有 `✦3` 角标；点详情 → 弹窗标签行 [原图][水墨国风][光影焕新]，字段随标签切换（画风/源自/状态不同）；衍生行列表缩略带滤镜+风格小标。
9. PC 上屏展示审核：FJDH-0002-02 水墨风格可见，详情弹窗同组合并展示。
10. PC 画风管理：菜单可进；列表含示例/名称/预计耗时/生成数量/提示词/状态；可编辑提示词、可启用/禁用即切即生效。
11. 界面文案无“AI / 智能”字样；风格作品界面无流水号（显示“风格名 · 源自 编号”）。

## 9. V2.3 相对 V2.1 的落地差异（改原型时已经拍板，后续不要回退）

1. **删除常驻“更多风格”区（本次亦改名“换个风格”）**：原方案详情页有“更多风格”大片卡片区（点卡生成）。落地改为**折叠进标签行**——标签行末尾 `+ 换个风格` 轻量弹层，非必要不保留常驻区块（用户明确：考虑交互，减少一屏堆叠）。
2. **保存/分享并列**：操作区改两个并列主按钮 `保存本地` / `分享上屏`（原“保存纪念照 + 底部分享这份美好”）。原因：分享入口原在最底部一屏看不到、容易遗漏。
3. **保存交互**：`保存本地` 点击即 toast「已保存」，不做长按弹层效果。
4. **画风大图**：CSS 滤镜示意，不做真实风格图（原型示意图，简单表达功能与逻辑）。
5. **PC 画风管理页本轮已实现**（原 V2.1 标 P1）：字段 = 示例/名称/预计耗时/生成数量/提示词/状态，支持编辑提示词、启用禁用。
6. **PC 详情弹窗同组合并 + B02 成像风格列 + 画风管理去生成数量 + 模板管理精简**：原图 + 全部风格在一个弹窗内标签切换（方案1 镜像），公共字段固定、作品字段跟随标签。
