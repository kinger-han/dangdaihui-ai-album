# PRD 待更新清单（原型口径差异）

> 原型改动与 PRD 不同步时，差异一律**追加**到本文件（按批次编号），写法：改了什么 + 业务原因 + 原口径。
> PRD 本体只在明确要求「更新 PRD」时批量落地，届时 grep 全库旧口径一并改净。

## 批次 01 · 2026-10-08 · PC 原型与真实系统（智汇平台）对齐

来源：用户提供 10 张真实系统功能页截图（`UI设计图+截图/系统截图/`），要求原型与真实功能页保持一致。本次只改 PC 原型，未动移动端、未动 PRD 本体。

### 1. 新增字段：画风管理「合成模式」（真实系统已上线，截图较早未体现）
- 改了什么：画风管理列表在「画风名称」后新增「合成模式」列，取值 `默认合成` / `模型合成`；新增/编辑画风弹窗同步新增该字段（必填，默认「默认合成」）；演示数据中「经典庄重」= 模型合成，其余 = 默认合成。
- 业务原因：党代会场景需要把人像抠出后贴到统一背景模板（换背景）产出统一纪念照；现有风格迁移链路不覆盖该模式，需用字段区分两条合成链路并分别配置提示词。
- 原口径：PRD 画风模块字段仅「画风名称 / 预计耗时 / 提示词 / 状态」，无合成模式。

### 2. 设备管理由占位页改为完整页面
- 改了什么：新增 `prototype/pages/pc/05-device-mgmt.html`；列 = 设备名称 / 设备 MAC / 轮播首图 / 设备二维码 / 悬浮二维码 / 排序 / 更新时间 / 操作；支持设备名称·MAC 搜索、新增/编辑弹窗（轮播首图与悬浮二维码为图片上传）、单项删除、批量删除、分页；shell 菜单由占位函数改为真实页面跳转。
- 业务原因：真实系统设备管理是独立模块；设备名同时是照片「来源屏幕 / 上屏屏幕」的取值来源。
- 原口径：PRD 与原型将设备管理标为「原型暂未实现，仅菜单占位」。
- 待确认：真实系统新增设备弹窗是否含「排序」维护项（4.1 截图未见），如需在弹窗维护排序告知后补。

### 3. 上屏审核「选择上屏设备」弹窗：设备分组单选 → 多选表格
- 改了什么：弹窗改为「设备名称搜索 + 设备表格（复选框 / 设备名称 / 设备 MAC / 更新时间）+ 表头全选 + `确认（N）` 按钮」；多选结果以顿号拼接写入该照片的「上屏屏幕」；未选设备时确认按钮置灰。
- 业务原因：与真实系统交互一致（一张照片可同时上屏到多块屏）。
- 原口径：PRD 为「主屏 / 副屏」两级单选分组。

### 4. 列表字段、筛选与文案口径对齐
- 照片管理：列名「成像风格 → 画风」「微信号 → 账号」；新增列「上屏屏幕」；统计卡文案改为「纪念照片数 / 分享上屏人数 / 留下纪念人数」（后两者按账号去重）；筛选改为 状态 / 模板 / 照片方向 / 来源屏幕 / 上屏屏幕 / 照片编号；按钮改为 重置 / 搜索 / 批量删除。
  - ⚠️ 口径需确认：三个统计卡目前按「账号去重」计算（照片数 14 → 分享上屏人数 5 / 留下纪念人数 11）。真实系统三个数字的实际统计口径（是否按人数、是否含重复扫码）需与研发确认。
- 上屏审核：菜单与面包屑改为「上屏审核」（页内标题保留「上屏展示审核」）；补齐与照片管理一致的筛选与列。
- 模板管理：列名「方向 → 模板方向」，取值由「横版/竖版」改「横屏/竖屏」；状态措辞「禁用」改「停用」；去掉页头标题、按钮移入筛选栏；新增批量删除。
- 画风管理：状态措辞「禁用」改「停用」；新增「排序」列与排序维护项；新增批量删除。
- 业务原因：界面中文案与真实系统逐字对照，避免客户对照时出现差异。
- 原口径：PRD 与原型沿用旧列名（成像风格 / 微信号）、旧取值（横版 / 竖版）与旧措辞（禁用）。

### 5. 分页组件
- 改了什么：5 个列表页统一分页条（共 N 条 / 10条/页 / 页码 / 前往 N 页），每页 10 条，超出时真实翻页。
- 业务原因：真实系统列表均带分页；原原型为「上一页 / 下一页」简易分页或无分页。
- 原口径：PRD 未定义分页规格。

### 6. 演示数据口径
- 「来源屏幕 / 上屏屏幕」取值由「1号屏 / 2号屏」改为设备名（`测试`、`P43-纪念相册`）。
- 时间统一为 `YYYY-MM-DD HH:MM:SS`。
- 设备与画风数据上移为全局共享源（`window.__DEVICE_LIST` / `window.__STYLE_LIST`），设备管理页、上屏设备弹窗、来源屏幕·上屏屏幕筛选共用同一份数据。
