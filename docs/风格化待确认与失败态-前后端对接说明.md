# 风格化 · 待确认与失败态（0907 上午改动）前后端对接说明

> 适用范围：党代会 AI 纪念相册 手机 H5 + PC 管理端。给开发 AI / 工程师按此实现，与原型（dist 最新版）一致。
> 关联文档：PRD V2.0（`AI纪念相册产品原型设计PRD.md`）、原型 dist（mobile / pc）。
> 日期：2026-09-07。本文只描述本次改动的事实与要求，不写未实现方案。

---

## 0. 本次改动一句话

风格照生成改为「**异步任务 → 待确认池 → 用户确认（采用）**」：生成结果不立即变成正式作品，先进**待确认**；用户保存（采用）后才进我的纪念、可上屏。配套：失败态、生成中状态、前台去流水号、PC 运营统计列。

## 1. 移动端（H5）改动

### 1.1 入口与弹窗（详情页 08-result）

- 详情页为**单作品视图**（原图或某张风格照各为一张独立作品），**无标签行、无标签切换**。
- 常驻按钮 **`更多风格`**（位于编号下方、操作区上方）：点开**半屏弹窗**，列出**全部启用画风**（同底片同画风只允许一张，重复生成由按钮态禁止）。
- 弹窗画风项 = 示例图（画风滤镜缩略）+ 名称 + 预计耗时 + 描述 + 状态按钮（随该画风当前状态切换）：
  - 未生成 → `生成`（点击后**立即**变为 `生成中…`，可离开页面后台继续）；
  - 生成中 → `生成中…`（转圈）；
  - 待确认 → `待确认`（打开确认卡三选一）；
  - **已保存为正式作品 → `查看`（跳到该风格照详情页，可保存本地/分享上屏）**。
  - **一次只跑一个任务**：生成中再点其他画风 → toast「已有风格生成中」。
- 生成中动效：`更多风格` 按钮**金色光晕呼吸**（发光）；有待确认未读时按钮右上**红点**。

### 1.2 待确认池（核心）

- 生成完成 = 进入**待确认**（不立即是正式作品、不进正式列表）。
- 三个提醒位（同一待确认池）：
  1. 首页「我的纪念照」按钮右上红点（未读待确认数，未读 = 未查看过）；
  2. 我的纪念页顶部 **「风格照生成」区**：列出 **生成中 + 失败 + 待确认** 全部；顺序：生成中 → 失败 → 待确认；
  3. 详情页「更多风格」按钮红点（当前底片的未读待确认数）。
- **红点 = 未读标记**：点开确认卡（查看）即清红点，但未保存仍留在待确认区；保存/放弃后才移出。
- 待确认项卡：缩略 + 画风名 + 「第 N 号纪念档案」+ 右侧 `待确认`（未读带红点）。
- **跨会话持久**：待确认作品不随用户退出丢失，重新进入仍可看到并确认。

### 1.3 确认卡（半屏弹层，全局层）

点「待确认」/待确认卡 → 打开**确认卡**：
- 大图预览（画风滤镜）+ 画风名 + 说明；
- 三选一：
  - `保存到纪念照` → 成为**正式作品**（编号顺延、进我的纪念、可保存本地/分享上屏/三态）；保存后跳到该作品正式详情页；
  - `重新生成` → 同画风重跑（覆盖当前待确认，完成后重新入池）；
  - `放弃这张风格照` → 移除待确认，画风回到可生成状态。

### 1.4 生成中状态卡

我的纪念「风格照生成」区点「生成中」项 → 打开状态卡：缩略 + 转圈「生成中…」+ 画风名 + 说明「正在生成，最快约 1-2 分钟。完成后回到这里会变成『待确认』，你可以确认保存或重新生成。」+ `知道了`（无操作按钮）。

### 1.5 失败态

- 生成任务失败 → 我的纪念「风格照生成」区出现**失败卡**：缩略（盖 ✕ 灰蒙）+ 画风名 + 「生成没有完成」+ 右侧红字 `生成失败`。
- 点失败卡 → 失败卡弹层（半屏）：`重新生成`（同画风重跑，成功后进待确认）/ `放弃这张风格照`（移除）/ `暂不处理`。
- 失败**不产生作品、不进待确认、不落我的纪念**；原图始终可保存。
- 原型演示：
  - **手绘插画（shouhui）固定失败**（数据层 `demoFail: true`，生成必失败）；
  - 演示菜单（右下 FAB）「风格照生成失败」可在详情页发起任意画风强制失败（`genNextFail`）。

### 1.6 前台去流水号

- 详情页原图显示 `第 328 号纪念档案`；风格照详情只显示画风名（`水墨国风`）。
- 我的纪念卡：原图/风格照都**不显示编号**（只显示模板/风格名/时间/状态）。
- 现场风采（墙上）：**不显示编号**；风格照右下角显示**画风名角标**（如 `水墨国风`），普通照无角标；详情照片带同款角标 + 副标题 `水墨国风 · 点击可拍同款`。
- 导出成品图**不印编号**。

### 1.7 其他

- 拍照直出：点「立即生成纪念照片」**直接进结果页**（无生成过渡动画页）；生成失败仍走失败页（demo 菜单可触发直出失败）。
- 直出模板耗时文案（约 3 秒）为实时合成能力描述，**不改**。

## 2. 数据模型与接口（后端）

### 2.1 作品表（Work）

| 字段 | 说明 | 备注 |
|---|---|---|
| `no` | 作品编号（主键/统计） | 全局流水：直出 FJDH-0328-01…，风格作品顺延；**前台不再展示** |
| `visitorId` | 访客（匿名 token） | |
| `tpl` | 模板 id | 2 个经典框 |
| `style_id` | 画风 id | 空 = 直出 |
| `source_work_id` | 来源原图作品 id | 风格作品指向原图；直出为空 |
| `status` | 生成/审核/上屏状态 | 沿用 |
| `time` / 时间字段 | 创建等 | |

> 前台不展示 `no`，但 PC 台账完整编号照常展示（统计/检索用）。

### 2.2 生成任务表（新增，承载待确认/失败/统计）

| 字段 | 说明 |
|---|---|
| `taskId` | 任务 id（90s+ 异步） |
| `work_id` | 生成结果（待确认/正式作品） |
| `visitor_id` | 访客 |
| `source_work_id` | 哪张底片（**同底片同画风只允许一张**的查重依据：source_work_id + style_id 唯一） |
| `style_id` | 画风 |
| `status` | `生成中 processing / 成功 success / 失败 fail` |
| `confirm_status` | `待确认 pending / 已保存（采用）kept / 已放弃 dropped / 已重新生成 regenerated` |
| 时间 | 发起 / 完成 / 确认 |

### 2.3 状态语义（移动端 ↔ 后端）

- 生成中 = task.status = processing；
- 待确认 = task.status = success 且 confirm_status = pending（**未确认前不发布正式作品**）；
- 正式作品 = confirm_status = kept（才可保存本地/分享上屏/三态）；
- 失败 = task.status = fail（前端显示失败卡，重新生成 = 再起任务，放弃 = 删除）。

### 2.4 接口建议

| 接口 | 用途 |
|---|---|
| `GET /styles` | 画风列表（`enabled` 热开关、`prompt`、预计耗时） |
| `POST /works/{id}/style-tasks` | 发起风格生成（body: style_id），同源同画风唯一 |
| `GET /style-tasks?visitor={id}` | 我的待确认/生成中/失败列表（confirm_status + status） |
| `POST /style-tasks/{id}/confirm` | 确认动作：`keep`（保存到纪念照）/ `regenerate`（重新生成）/ `drop`（放弃） |
| `GET /styles`（运营字段） | 返回 `gen/keep/drop/fail` 累计统计（见 3.1） |

## 3. PC 端改动

### 3.1 画风管理（04-style-mgmt）

列表新增运营统计列：**生成 / 采用 / 弃用 / 失败**：
- `gen` 生成成功次数；`keep` 采用（确认保存）次数；`drop` 弃用次数；`fail` 生成任务失败次数。
- 口径为**累计终态**：生成+失败 = 任务完成数；采用+弃用 = 已确认数。**不设「生成中」列**（中间态不进累计统计；实时并发监控属数据统计页）。
- 演示数据：光影焕新 12/9/3/1、水墨国风 9/6/3/2、手绘插画 5/2/3/5（失败率高，与移动端手绘插画固定失败演示一致）。

### 3.2 照片管理（01-photo-mgmt）与上屏展示审核（02-selection-mgmt）

- 新增 **`成像风格` 列（单值）**：原图 = `原图`；风格照 = 画风名。原图与风格照**各为独立数据行**（不合并、无角标、无「源自」标注）。
- 照片详情弹窗：单作品视图 + **`成像风格` 字段**（原图/画风名）；字段 = 模板、成像风格、微信号、来源屏幕、上屏状态、创建时间、上屏展示时间、下屏时间。
- 风格作品的缩略图带画风滤镜、模板列无额外小标。
- 删除按作品维度（连带删同源风格作品）。

### 3.3 数据源

原型 `window.__STYLE_LIST` = 画风配置 + 运营统计（正式版 `GET /styles` 返回）；`window.__PHOTO_DETAILS` / 页面 mock = 作品台账。

## 5. 验收清单

### 移动端
1. 详情页点「更多风格」→ 弹窗选画风 → 按钮秒变「生成中…」（弹窗不关，10s 后变「待确认」）
2. 首页/我的纪念/详情按钮红点随待确认未读变化；点开确认卡即清红点
3. 我的纪念「风格照生成」区：生成中（点开状态卡）/ 失败（点开失败卡）/ 待确认（点开确认卡）全量展示
4. 待确认 → 保存到纪念照 → 正式作品（可上屏/三态）；重新生成 → 覆盖重跑；放弃 → 移除
5. 手绘插画生成必失败；失败卡重新生成/放弃可用
6. 前台无作品流水号（详情/我的纪念/墙）；风格照墙标是画风名
7. 待确认跨会话保留（后端接入后验证）

### PC 端
1. 画风管理四列统计齐全且为终态口径
2. 照片管理/上屏审核的成像风格列单值正确；风格照独立行、详情弹窗含成像风格字段
3. 照片详情弹窗无标签行/无源自字段
