# 会场体验海报 · 文案要素

> 党代会现场，2 张海报固定在会场屏幕，引导参会人员扫码体验。给设计部门出稿用，版式、配色、创意自由发挥。

## 海报 A · 问境（AI 问答）
- **一句话定位**：现场"有事问 AI"，扫二维码即可向党建智慧助手提问，随问随答。
- **主标题（推荐）**：有问题，随时问
- **功能亮点**（写 2-3 条即可）：
  1. 大会信息：会议安排、代表履职、媒体资讯
  2. 现场服务：场馆指引、失物招领、应急求助
  3. 权威可靠：基于大会知识库，不编造
- **CTA**：扫一扫，马上问

## 海报 B · AI 纪念相册
- **一句话定位**：留下这一刻，现场拍照秒出专属纪念照，可保存分享、参与现场大屏展示。
- **主标题（推荐）**：留下这一刻，带走专属纪念
- **功能亮点**：
  1. 一拍即得：现场拍照，经典纪念框秒级合成
  2. 专属纪念：每一份都有专属纪念档案
  3. 现场风采：授权后，作品有机会登上现场大屏
- **CTA**：扫码拍照，留存纪念

## 通用要求
1. **两海报风格统一**，同套视觉，形成系列。
2. **主色调**：红金党政风。
3. **二维码**：真实可扫、视觉突出（占屏大一些），可加轻动效（呼吸光圈/扫描线）引导扫码；旁配"微信扫一扫"。
4. **落款**：数熙科技（待确认，也可能不放）。

## 红线（必须遵守）
- 助手自称"**智能助手**"，**禁出现"导游"**；对用户称"您"。
- 相册文案**禁"精选/审核"**，用"**风采/展示/亮相**"。
- **不承诺上屏**：写"有机会登上现场大屏"。
- **不夸大 AI**：纪念照是模板合成，不写"AI 生成虚拟形象"等。
- 大会全称统一「中国共产党福建省第十二次代表大会」；不出现党徽党旗生成效果、政治人物合影。
