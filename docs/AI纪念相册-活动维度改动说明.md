# 党代会 · AI 纪念相册｜新增活动维度--改动说明

> 本次核心：改成**多客户 / 多活动的标准产品**，前台扫码后按活动隔离。
> 涉及页面：活动管理（新增）、模板管理、照片管理、上屏审核、设备管理、画风管理。
> 移动端本次未改。

---

## 1、功能页面：活动管理（新增页面）

数据的最上层归属：活动 → 客户 → 设备 / 模板 / 画风 / 照片。

### （1）字段

**列表页筛选区**

| 字段   | 控件类型       | 说明                   |
| ---- | ---------- | -------------------- |
| 活动名称 | 单行文本（模糊匹配） | 输入即筛选                |
| 所属客户 | 下拉单选       | 只列活动管理中的客户           |
| 活动状态 | 下拉单选       | 全部 / 未开始 / 进行中 / 已结束 |

**新增 / 编辑弹窗 — 页签 1「基础信息」**（字段顺序即界面顺序）

| 序   | 字段   | 属性           | 控件类型              | 必填    | 读/写 |
| --- | ---- | ------------ | ----------------- | ----- | --- |
| 1   | 活动名称 | `name`       | 单行文本              | **是** | 可编辑 |
| 2   | 所属客户 | `customerId` | 下拉单选（全部客户）        | **是** | 可编辑 |
| 3   | 活动状态 | `status`     | 下拉单选（未开始/进行中/已结束） | **是** | 可编辑 |
| 4   | 活动介绍 | `intro`      | 多行文本              | 否     | 可编辑 |
| 5   | 开始日期 | `startTime`  | 日期选择器             | 否     | 可编辑 |
| 6   | 结束日期 | `endTime`    | 日期选择器             | 否     | 可编辑 |

**新增 / 编辑弹窗 — 页签 2「创作能力」**（字段顺序即界面顺序）

| 序   | 字段   | 属性             | 控件类型                  | 必填  | 读/写 |
| --- | ---- | -------------- | --------------------- | --- | --- |
| 1   | 启用画风 | 派生自画风 `actIds` | 多选表格（搜索框 + 全选 + 逐行勾选） | 否   | 可编辑 |
| 2   | 启用模板 | 派生自模板 `actIds` | 多选表格（搜索框 + 全选 + 逐行勾选） | 否   | 可编辑 |

- 启用画风表格列：☐ / 示例 / 画风名称 / 合成模式 / 状态
- 启用模板表格列：☐ / 模板图片 / 模板名称 / 模板方向 / 状态
- **「启用」是「启用」的展示位**，不改变模板/画风自身的「状态（启用/停用）」，两者是独立维度

### （2）列表：显示字段及顺序

| 序   | 列名      | 来源                      | 说明                          |
| --- | ------- | ----------------------- | --------------------------- |
| 1   | 活动名称    | `name`                  | —                           |
| 2   | 所属客户    | `customerId` → 客户表      | 活动带出                        |
| 3   | 活动状态    | `status`                | 彩色标签：未开始（蓝）/ 进行中（绿）/ 已结束（灰） |
| 4   | 开始/结束日期 | `startTime` + `endTime` | 上下两行展示                      |
| 5   | 更新时间    | `updateTime`            | 每次保存 / 改状态自动刷新              |
| 6   | 操作      | —                       | 编辑 · 删除（活动状态在编辑弹窗手动维护）     |

### （3）权限与操作逻辑

**权限**

| 操作          | 权限      | 说明                                                                           |
| ----------- | ------- | ---------------------------------------------------------------------------- |
| 查看列表 / 查看详情 | 登录用户可   | 只读                                                                           |
| 新建活动        | 管理端用户   | 弹窗新增                                                                         |
| 编辑活动        | 管理端用户   | 弹窗修改；**活动状态（未开始 / 进行中 / 已结束）在此手动切换**，不做行内快捷启停                |
| **删除活动**    | **管理员** | 活动是设备与照片的归属根节点。**存在设备记录（含停用）或照片时阻断删除**，并提示「还有 X 台设备记录、Y 张照片」，请先删除/改投设备、清理照片后再试；**模板 / 画风是全局资源池的多选引用（归属活动），不阻断删除**——删除时自动从相关模板 / 画风的 `actIds` 中移除本活动，并在确认弹窗中提示将解除 N 个模板、M 个画风的关联 |

**操作逻辑**

| 操作  | 前置校验            | 结果                                               |
| --- | --------------- | ------------------------------------------------ |
| 新建  | 活动名称、所属客户必填     | 生成活动，状态默认「未开始」                                   |
| 编辑  | 同上              | 保存即刷新更新时间；状态由「活动状态」下拉手动切换，**状态切换只原地变色，不重排序**     |
| 删除  | 无设备记录（含停用）且无照片；二次确认 | 删除活动，同时自动解除模板 / 画风的归属关联（写回 `actIds`），列表刷新回第 1 页 |

**特殊逻辑：画风 / 模板双向同步（本次核心）**

- 模板、画风的「归属活动」是**多选**字段；活动的「启用画风 / 启用模板」是**派生视图**，两侧是同一份归属关系的两个方向。
- 在活动管理里勾选/取消 → 保存后写回模板/画风的「归属活动」，并同步刷新模板、画风两个列表页。
- 在模板/画风管理里改「归属活动」 → 保存后反写活动的「启用画风 / 启用模板」，下次打开活动弹窗即为已勾选状态。
- 一处改动、两处生效，无需手工两边对齐。

**特殊逻辑：活动状态与日期解耦**

- 状态**纯手动控制**，不随开始/结束日期自动流转。
- 日期只作为活动档期信息保存与展示，不参与状态判定。

**特殊逻辑：活动与设备联动（V2.2 测试完善）**

- 活动状态切为「已结束」→ **自动停用该活动下全部设备记录**（含启用中），该活动已上屏照片自动下屏。
- 状态切回「进行中」→ **不自动恢复任何设备**（含曾被其他活动占用的），需人工在设备管理逐台启用；启用时受 MAC 互斥校验约束（同一物理屏同时只能有一条启用记录）。

#### （2）新增列表显示字段

**模板管理**（列序）模板图片 → **归属活动** → 模板方向 → 适用建议 → 状态 → 使用次数 → 更新时间 → 操作

**画风管理**（列序）☐ → 示例 → 画风名称 → **归属活动** → 合成模式 → 预计耗时 → 提示词 → 生成 → 采用 → 弃用 → 失败 → 状态 → 排序 → 操作

**照片管理**（列序）☐ → 纪念照 → 编号 → **所属活动** → **所属客户** → 模板 → 画风 → 账号 → 上屏屏幕 → 来源屏幕 → 上屏状态 → 创建时间 → 操作

**上屏审核**（列序）☐ → 纪念照 → 编号 → **所属活动** → **所属客户** → 模板 → 画风 → 账号 → 上屏屏幕 → 来源屏幕 → 上屏状态 → 上屏时间 → 操作

**设备管理**（列序）☐ → 设备名称 → **所属活动** → **所属客户** → 设备 MAC → **启用状态** → 轮播首图 → 设备二维码 → 悬浮二维码 → 排序 → 更新时间 → 操作

**详情弹窗**（照片管理 / 上屏审核共用，新增 3 个只读字段）

| 字段   | 属性      | 读/写    | 取值逻辑                       |
| ---- | ------- | ------ | -------------------------- |
| 所属活动 | `actId` | **只读** | 生成时按「来源屏幕」对应设备记录所属活动**快照** |
| 所属客户 | —       | **只读** | 由所属活动带出                    |
| 画风   | —       | **只读** | 原图画风显示「原图」，风格照显示画风名        |

> 归属为**快照**而非实时关联：设备后续改投别的活动，历史照片的归属不变。

#### （3）筛选字段

**五个页面统一新增「所属客户」+「所属活动」两个筛选**，且**级联**：先选客户 → 活动下拉收窄到该客户名下活动。

| 页面   | 筛选字段（界面顺序）                                                |
| ---- | --------------------------------------------------------- |
| 模板管理 | 模板名称 → 模板状态 → **所属客户** → **所属活动** → 模板方向                  |
| 画风管理 | 状态 → **所属客户** → **所属活动** → 画风名称                           |
| 照片管理 | **所属客户** → **所属活动** → 状态 → 模板 → 照片方向 → 来源屏幕 → 上屏屏幕 → 照片编号 |
| 上屏审核 | **所属客户** → **所属活动** → 状态 → 模板 → 照片方向 → 来源屏幕 → 上屏屏幕 → 照片编号 |
| 设备管理 | **所属客户** → **所属活动** → 启用状态 → 设备名称/MAC                     |

**筛选均为单选**，下拉结构 `全部 | 各客户… / 各活动…`，**无「未分配」项**（模板、画风、照片、设备归属均为必填）。

#### （4）本轮新增的业务约束

| 编号  | 约束                    | 说明                                                                   |
| --- | --------------------- | -------------------------------------------------------------------- |
| ①   | **同 MAC 单启用**         | 同一 MAC 地址在全系统只能有一条「启用」记录。新建/编辑保存时、行内启用时均校验，冲突时弹窗指出冲突设备名与所属活动，提示先停用那条 |
| ②   | **设备跨活动不复用**          | 同一块屏改投新活动时**新建一条设备记录**，原活动记录保留，原活动的照片与模板也全部保留                        |
| ③   | **行内启用/停用只原地变色**      | 状态切换后行位置不变，不重排序                                                      |
| ④   | **上屏候选按活动隔离**         | 上屏设备选择弹窗只列**该照片所属活动下已启用**的设备；弹窗顶部提示当前活动范围                            |
| ⑤   | **跨活动禁止批量上屏**         | 勾选的照片若分属不同活动，「批量上屏」置灰不可点，点击时二次拦截并提示。**不留跨活动投放后门**                    |
| ⑦   | **统计卡随筛选联动**          | 照片管理顶部 3 个统计卡（纪念照片数 / 分享上屏人数 / 留下纪念人数）随筛选结果实时重算                      |
| ⑧   | **列表排序**              | 照片管理、上屏审核按创建时间倒序；活动管理按更新时间倒序；其余页面维持原有排序（画风管理按 `sort` 升序）             |
| ⑨   | **现场风采隔离（口径，本次未改代码）** | 前台现场风采只展示**扫码屏所属活动**已上屏的作品，活动间不互通                                    |
| ⑩   | **同 MAC 换活动需更换二维码**   | 设备二维码/悬浮二维码按记录保存且内容含活动 ID，换活动后需重新出码。**属现场作业步骤**                      |
