# 风格照提示词（四风格 · 纯模型版）

> **实现前提**：本功能目前**仅依靠模型实现**——没有蒙版/区域控制、没有文字层后期合成。提示词是唯一的控制手段，模型必须同时做到「整体风格迁移」与「保持既有内容不坏」。
>
> **使用方式**：每条提示词都是一段**完整自包含**的文本，直接整段复制到后台画风管理对应的提示词字段即可，不需要拼接其他段落。

## 设计原则：分层

一刀切的「不新增元素」是错的——它把两个不同诉求挤在了一句话里：**不要动我原有的内容**（所有风格都成立）与**不要加莫名其妙的东西**（红绸是例外，它的环绕本身就是加元素）。正确做法是分层约束：

| 层 | 锁死 | 可随风格调整 |
|---|---|---|
| 政治标识（党徽、国徽、旗帜、五角星） | 有则原样保留——不移除、不变色、不淡化、不变形；无则不新增 | 无 |
| 模板构图（相框、装饰、底板、文字位置） | 位置、形状、构成关系、层级 | 颜色、明暗、质感 |
| 文字 | 内容、字形、排版位置 | 颜色、明暗 |
| 人物 | 面部特征与原图一致，不做重绘式变形 | 美颜（仅光影焕新）、风格化笔触 |
| 风格化元素（飘带、墨韵、笔触） | 不遮挡人脸与文字、不造成杂乱 | 按风格决定是否新增，强度分级 |

**逐风格的处理权限**：

| 风格 | 新增元素 | 模板处理 |
|---|---|---|
| 光影焕新 | 不加 | 不变色、不淡化，改造对象只有人脸与光影 |
| 红绸环绕 | 加飘带，强度自适应 | 形态不变，随整体转暖调 |
| 水墨国风 | 不加（靠留白，不靠贴素材） | 整体转水墨，红色系元素转墨/淡朱砂 |
| 手绘插画 | 不加 | 整体转水彩，色块与线条转手绘 |

## 三条由「纯模型」决定的写法

1. **文字要写「保留 + 授权调色」，不能写「不得重绘」**——模型分不清「改颜色」和「重绘」，写死不许动，它连风格该有的转色也不敢做。
2. **整体迁移必须显式点名区域**——不点名，模型默认只处理人脸，模板保持原始照片质感（这就是手绘插画「只迁移了人像」的原因）。
3. **红绸强度要给判断依据**——不能只说「自适应」，要告诉模型按「画面已有装饰元素的多少」来判断。

## 已知风险

纯模型没有兜底，文字被改坏的概率无法归零，只能靠负面提示词压低。**优先级：保结构 > 保风格强度**——风格弱了可以重试，字被改坏这张照片就废了。因此每条提示词都把「内容守恒」写在风格描述之前。

## 提示词 1：光影焕新

```
请以我提供的这张纪念照成品作为输入图，只做画风迁移，输出「光影焕新」效果，不要新增任何画面元素。必须遵守：①画面内容守恒：主体人物、模板相框、装饰纹样、全部文字、底板背景的内容与构图保持不变，不删除、不替换、不移位任何元素；②画面上原本已经存在的党徽、国徽、旗帜、五角星等政治标识一律原样保留，不得移除、不得改动、不得淡化、不得变形，同时也不要新增任何此类元素；③本次不做风格化改造，模板的相框、装饰与文字的原有色系和形态保持不变，全部文字的内容、字形、位置必须一字不改；④风格迁移作用于整个画面：在保持上述内容与色系不变的前提下，让整张照片的光影质感统一提升，人物、模板、背景一起处理，不要只处理人物；⑤人脸做自然美颜：均匀肤色、提升气色、淡化痘印泛红暗沉黑眼圈等临时瑕疵与油光，让人显得精神自然，但必须保留真实的皮肤纹理与毛孔，不磨皮、不塑料感、不假白、不蜡像感，脸型与五官比例不变，痣和雀斑等个人特征保留；⑥光影优化：适度提亮、柔和高光、提升暗部细节，画面通透干净，光线柔和自然有质感；⑦色调温暖，可加克制的金色光晕点缀，但不得覆盖或改动相框与文字区域；⑧不新增任何文字、字母、数字、印章、水印，不产生斜框、缺角、断线等变形。```

## 提示词 2：红绸环绕

```
请以我提供的这张纪念照成品作为输入图，只做画风迁移，输出「红绸环绕」效果。必须遵守：①画面内容守恒：主体人物、模板相框、装饰纹样、全部文字、底板背景的内容与构图保持不变，不删除、不替换、不移位任何元素；②画面上原本已经存在的党徽、国徽、旗帜、五角星等政治标识一律原样保留，不得移除、不得改动、不得淡化、不得变形，同时也不要新增任何此类元素；③模板的相框、装饰与文字保持原有形态与位置，全部文字的内容、字形、位置必须一字不改，允许随整体色调轻微调整明暗，但不得重写、不得改变字体、不得增删字；④风格迁移作用于整个画面：人物、模板、底板一起统一为暖调红金质感，不要只处理人物；⑤在画面中添加浅色丝绸飘带作为氛围元素，但强度必须自适应：若画面本身装饰元素已较多、色彩已较丰富，飘带要更少、更淡、更退让；若画面本身简洁，飘带可适度增强，整体以不遮挡人物面部与模板文字、不造成画面杂乱为准；⑥飘带用色要浅要透，使用浅绛红、藕红、朱砂淡染一类的低饱和红，避免高饱和正红、大红、暗红堆砌，避免大面积红色铺满画面；⑦飘带以局部环绕为宜，比如画面一侧或边角少量环绕，保留丝绸光泽与自然流动感，不得遮挡人物面部、不得压住模板文字；⑧底色以暖白、米金为主，红色只作点缀，整体清爽通透，喜庆而不压抑；⑨不新增任何文字、字母、数字、印章、水印，不产生斜框、缺角、断线等变形。```

## 提示词 3：水墨国风

```
请以我提供的这张纪念照成品作为输入图，只做画风迁移，输出「水墨国风」效果，不要新增任何画面元素。必须遵守：①画面内容守恒：主体人物、模板相框、装饰纹样、全部文字、底板背景的内容与构图保持不变，不删除、不替换、不移位任何元素；②画面上原本已经存在的党徽、国徽、旗帜、五角星等政治标识一律原样保留，不得移除、不得改动、不得淡化、不得变形，同时也不要新增任何此类元素；③风格迁移必须作用于整个画面，包括人物、模板相框、装饰纹样、文字与底板背景，全部一起转为水墨质感，不要只处理人物而保留其余部分的原始照片质感；④模板允许随风格调整：模板原有的红色系元素（文字、边框、装饰、色块）转为墨色或淡朱砂，整体降低饱和度、适度淡化，以契合水墨留白与素雅的意境，但元素本身的形态、位置与构成关系不变；⑤全部文字必须原样保留其内容、字形与排版位置，允许随整体转为墨色或淡色，但不得重写、不得改变字体、不得增删字；⑥画面呈现写意水墨：淡墨为主、墨色清透不浓重、留白自然，明亮雅致，不灰暗压抑；⑦人物的面部特征清晰可辨、与原图一致，不做重绘式变形；⑧不新增任何文字、字母、印章、水印，不产生斜框、缺角、断线等变形。```

## 提示词 4：手绘插画

```
请以我提供的这张纪念照成品作为输入图，只做画风迁移，输出「手绘插画」效果，不要新增任何画面元素。必须遵守：①画面内容守恒：主体人物、模板相框、装饰纹样、全部文字、底板背景的内容与构图保持不变，不删除、不替换、不移位任何元素；②画面上原本已经存在的党徽、国徽、旗帜、五角星等政治标识一律原样保留，不得移除、不得改动、不得淡化、不得变形，同时也不要新增任何此类元素；③风格迁移必须作用于整个画面，包括人物、模板相框、装饰纹样、文字与底板背景，全部一起转为手绘水彩质感，不要只处理人物而保留其余部分的原始照片质感；④模板允许随风格调整：模板原有的色彩转为淡雅手绘配色，色块转为水彩上色，边框与装饰线条转为柔和的手绘线条，但元素本身的形态、位置与构成关系不变；⑤全部文字必须原样保留其内容、字形与排版位置，允许随整体色调轻微调整颜色与明暗，但不得重写、不得改变字体、不得增删字；⑥整体呈现清新细腻的手绘水彩：手绘线条、淡彩上色、笔触柔和、色彩淡雅温暖，可有纸张纹理感；⑦人物的面部特征清晰可辨、与原图一致，不做重绘式变形；⑧不新增任何文字、字母、数字、印章、水印，不产生斜框、缺角、断线等变形。```
