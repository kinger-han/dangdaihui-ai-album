# 风格照提示词（四风格 · 带模板版）

> 用法：后台把**已生成的纪念照成品**（含模板底板、相框、文字层）作为输入图，把对应画风的提示词作为 prompt 一起送给大模型。
> 每条提示词**自包含**，可整段直接复制使用，不依赖其他段落。
> 输出 = 同一张纪念照的画风迁移版本，模板框与文字原样保留。

---

## 模板文字层（不进模型，仅作核对）

| 元素 | 内容 |
|---|---|
| 大会名称 | 聚焦中国共产党福建省第十二次代表大会 |
| 落款 | **2026.11·福建福州** |
| 编号 | 第 N 号纪念档案（系统合成） |

> ⚠️ 该层由模板素材 / 后期合成提供，不交给生成模型。底板图上的落款若非此文案，需设计侧同步更新素材，保证直出纪念照与风格照一致。

## 提示词 1 · 光影焕新

```
请以我提供的这张纪念照成品作为输入图，只做画风迁移，输出「光影焕新」效果。必须遵守：①主体人物、模板底板、相框、框上文字、背景的内容与构图完全保持不变，不新增、不删除、不替换、不移动任何元素；②模板原有的相框、描边、装饰和全部文字原样保留，不要重绘、不要改字、不要重新排版；③画面上原本已经存在的党徽、国徽、旗帜、五角星等元素一律原样保留，不得移除、不得改动、不得重新绘制，同时也不要新增任何此类元素；④人脸做自然美颜：均匀肤色、提升气色、淡化痘印泛红暗沉黑眼圈等临时瑕疵与油光，让人显得精神自然，但必须保留真实的皮肤纹理与毛孔，不磨皮、不塑料感、不假白、不蜡像感，脸型与五官比例不变，痣和雀斑等个人特征保留；⑤画面整体做光影优化：适度提亮、柔和高光、提升暗部细节，通透干净，光线柔和自然；⑥色调温暖，可加克制的金色光晕点缀，但不得覆盖或改动相框与文字区域；⑦不新增任何文字、字母、数字、印章、水印，不产生斜框、缺角、断线等变形。
```

## 负面提示词（接口支持时按画风附加）

- 通用：`重绘相框, 改动文字, 错字, 变形边框, 斜框, 缺角, 断线, 换脸, 磨皮, 塑料感皮肤, 过度美白, 假白假面, 蜡像感, 新增文字, 水印, 印章, 新增党徽, 新增国徽, 新增旗帜, 移除原有元素`
- 光影焕新追加：`油光, 暗沉`
- 红绸环绕追加：`高饱和正红, 大红, 红色堆砌, 红绸遮脸`
- 水墨国风追加：`浓墨, 灰暗压抑, 动漫`
- 手绘插画追加：`动漫二次元, 厚涂油画, 夸张变形`
