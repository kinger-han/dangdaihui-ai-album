# 会场体验海报 · 文案要素与设计需求单

> 背景：福建省第十二次党代会现场，智融屏互动 POC。
> 用途：2 张海报，固定展示在会场屏幕（电子屏画面），介绍功能并引导参会人员扫码体验。
> 交付对象：设计部门（凭本文档出设计稿）
> 版本：V1.0（2026-09-04）

---

## 0. 两张海报一览

| | 海报 A · 智能问答 | 海报 B · AI 纪念相册 |
|---|---|---|
| 定位 | 现场 AI 问询服务，有问题随时问 | 互动留影，留下纪念 |
| 目标动作 | 扫码提问 | 扫码拍照生成纪念照 |
| 核心价值 | 随问随答、权威可靠、现场服务 | 一拍即得、专属纪念、现场风采 |

> 建议统一版式骨架：品牌区（顶部）→ 主标题（中央大字）→ 功能点（中部）→ CTA + 二维码（底部）。
> 两张海报同套视觉语言，形成系列感。

---

## 1. 海报 A · 问境（AI 智能问答）

### 1.1 定位语（给设计的一句概述）
现场版的"有事问 AI"：参会人员扫二维码，即可向党建智慧助手提问——大会信息、会务服务、现场指引，随问随答。

### 1.2 文案层级

| 层级 | 文案（推荐） | 备选 |
|---|---|---|
| 主标题 | **有问题，随时问** | 问境 · 党建智慧助手 / 大会信息、会务指引，一问便知 |
| 副标题 | 党建智慧助手 · 现场 AI 问询服务 | 基于大会知识库，权威可靠 |
| 功能点 1 | 大会信息：会议安排、代表履职、媒体资讯 | 会议程序 / 大会公开信息 |
| 功能点 2 | 现场服务：场馆指引、失物招领、应急求助 | 会务指引 / 现场求助 |
| 功能点 3 | 权威可靠：基于大会知识库，不编造 | 有依据才回答 |
| CTA | **扫一扫，马上问** | 扫码提问，即刻解答 |
| 二维码引导 | 微信扫码，体验 AI 智能助手 | 长按识别二维码 |

### 1.3 文案要点提示
- 场景是政务/党建，助手自称"**智能助手**"，严禁出现"导游"字样。
- 对用户一律称"您"，语气庄重克制。
- 突出"现场服务"（会场指引、求助类），这是区别于通用问答的差异化亮点。

## 2. 海报 B · AI 纪念相册

### 2.1 定位语（给设计的一句概述）
"留下这一刻"：现场拍照，AI 智能合成专属纪念照，保存分享；作品可参与现场大屏风采展示。

### 2.2 文案层级

| 层级 | 文案（推荐） | 备选 |
|---|---|---|
| 主标题 | **留下这一刻，带走专属纪念** | AI 纪念相册 · 定格盛会时光 / 拍一张照片，存一份纪念 |
| 副标题 | 现场互动留影 · 秒出纪念照 | 扫码拍照，AI 智能合成 |
| 功能点 1 | 一拍即得：现场拍照，经典纪念框秒级合成 | 全程 3 分钟：扫码、创作、保存 |
| 功能点 2 | 专属纪念：生成独一无二的纪念档案 | 每一份都有专属纪念编号 |
| 功能点 3 | 现场风采：授权后，作品有机会登上现场大屏 | 参与现场大屏展示 |
| CTA | **扫码拍照，留存纪念** | 拍一张，带回家 |
| 二维码引导 | 微信扫码，领取你的纪念照 | 扫码创作纪念照 |

### 2.3 文案要点提示（红线，务必遵守）
- **禁用"精选/审核"字眼**，统一用"**风采/展示/亮相**"。（现场表现：提交后"等待展示"，不说"审核"）
- **不承诺上屏**：写"有机会登上现场大屏 / 可参与现场大屏展示"，禁止"作品将在大屏播出"等确定性表述。
- **不夸大 AI 能力**：当前实际能力是照片 + 经典纪念框模板合成（1-3 秒），写"智能合成/经典纪念框"，不写"AI 生成你的虚拟形象、AI 海报"等。产品名"AI 纪念相册"保留即可。
- 纪念作品称"纪念档案/纪念照"，不写"第 N 位代表"之类身份表述。

## 3. 二维码与"可扫码"设计要求

海报固定在屏幕上，二维码是核心转化入口，须满足：

1. **真实可扫**：二维码区必须放真实二维码（当前用演示环境链接生成的二维码，正式链接确定后替换）。
2. **视觉突出**：
   - 二维码占屏面积建议 ≥ 屏宽 1/4；
   - 黑白对比度 ≥ 4.5:1，四角留白 ≥ 码宽 1/10，避免花哨底纹干扰识别；
   - 屏幕扫码距离较远（1-3 米），二维码尺寸宁大勿小。
3. **扫码引导动效**（屏幕海报特有，加分项）：二维码周围加"呼吸光圈 / 扫描线"轻动效，或手机图标 + 波纹示意，引导现场人员举手机扫码。动效需克制，不干扰阅读。
4. 二维码旁配"微信扫一扫"图标与提示文字。

## 4. 整体红线（两张海报通用）

| 类别 | 要求 |
|---|---|
| 大会名称 | 统一「中国共产党福建省第十二次代表大会」，不缩写 |
| 影像内容 | 不出现党徽、党旗生成效果，不出现政治人物合影/装扮 |
| 品牌落款 | 数熙科技（待确认：是否落款、落款形式） |
| 语气 | 政务场景，庄重、克制、不用网络流行语 |
| 主色调 | 红金党政风（与原型一致） |

---

## 5. 待确认项（找客户/项目负责人拍板）

1. 海报落款：是否显示"数熙科技"，还是大会主办方名？还是不加落款？
2. 屏幕实际尺寸/比例（竖屏 9:16 或 3:4？）——设计按实际屏幕出稿。
3. 两张海报是否同屏轮播还是一屏一张固定画面。
4. 二维码正式链接何时确定（确定前先排演示用码）。

---

## 6. 给设计的出稿规格建议

- 文件：竖版电子屏海报，建议 1080 × 1920（按实际屏幕比例缩放），PNG/JPG + 可编辑源文件（AI/PSD）。
- 同时给一版"静态码"便于测试；若支持动效，额外给 MP4/GIF 循环版。
- 交付时包含：2 张主图 + 二维码替换说明（正式码出来后可原位替换）。
