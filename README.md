# 党代会 AI 纪念相册 · 手机 H5 + B 端管理原型

> 项目：中国共产党福建省第十二次代表大会 · 智融屏互动 POC
> 形态：手机 H5（微信扫码）+ PC 端 B 端管理（build.py 组件化工程）
> 版本：V3.1（工程化，2026-09-02：B 端状态上屏化 + 模板管理精简 + H03 平铺）

## 结构与构建

```
prototype/
├── proto-config.json          # 项目配置（名称/主色/tabBar）
├── shell-mobile.html          # 移动端壳：全面屏居中手机框 + 业务样式
├── shell-pc.html              # PC 端壳：侧边栏 + 菜单（项目级副本）
├── pages/
│   ├── mobile/                # 手机 H5 12 页组件（分页源码）
│   │   ├── 01-home.html       # H01 活动首页（含共享数据/导航）
│   │   ├── 02-create.html     # H02 创作方式
│   │   ├── 03-templates.html  # H03 模板列表
│   │   ├── 04-tpl-detail.html # H04 模板详情
│   │   ├── 05-photo.html      # H05 获取照片（含授权弹层）
│   │   ├── 06-photo-confirm.html # H06 照片确认（质量检测）
│   │   ├── 07-generating.html # H07 生成进度（含失败恢复）
│   │   ├── 08-result.html     # H08 作品结果（保存/分享/精选）
│   │   ├── 09-gallery.html    # H09 精选照片墙
│   │   ├── 10-mine.html       # H10 我的纪念
│   │   ├── 11-terms.html      # H11 说明与授权
│   │   └── 12-status.html     # H12 活动状态
│   └── pc/                    # PC 端 B 端管理页
│       ├── 01-photo-mgmt.html     # 照片管理（总台账 + 上屏）
│       └── 02-selection-mgmt.html # 精选管理（用户同意上屏）
└── dist/                      # 构建产物（只读）
    ├── 党代会-AI纪念相册-mobile-原型.html
    └── 党代会-AI纪念相册-pc-原型.html
```

构建命令（prototype-kit 工具包）：
```bash
python build.py mobile --project-path=<项目目录>
python build.py pc --project-path=<项目目录>
```

## 手机 H5 覆盖（PRD H01-H12 完整闭环）

- H01 首页 / H02 创作方式 / H03 模板列表 / H04 模板详情 / H05 获取照片（首次授权弹层）/ H06 照片确认（质量三态）/ H07 生成进度（分能力阶段+失败恢复）/ H08 作品结果（保存、分享海报、现场精选授权提交）/ H09 精选照片墙（拍同款）/ H10 我的纪念 / H11 说明与授权 / H12 活动状态
- 右下角「演示」按钮可切换：活动未开始/暂停/结束/链接无效/网络异常、质量检测可继续/阻断、生成失败（通用/内容安全）

## PC 端 B 端管理

- **照片管理**：活动内全部照片总台账（纪念照/编号/模板/微信号/来源屏幕/上屏状态/创建时间），筛选（上屏状态三态：正在展示/等待上屏/暂未分享、模板），筛选栏批量删除，详情弹窗字段精简 + 照片点击放大
- **上屏展示审核**：用户已授权同意展示的照片，行操作 上屏/下屏，批量上屏/批量下屏（按勾选类型精确启用），上屏选目标屏幕并记录上屏时间

## 红线落实（对照 PRD）

- 大会全称统一「中国共产党福建省第十二次代表大会」
- 纪念编号「第 N 号纪念档案」+ FJDH 编号，不写"第 N 位代表"
- 不承诺上屏：提交后提示「已提交现场精选」「等待精选」
- 未勾选授权不能提交现场精选；照片墙/大屏不显示姓名
- 模板、文案、统计数字全部数据驱动（组件顶部数据区）
