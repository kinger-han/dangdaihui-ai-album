## 原型覆盖（PRD H01-H12 完整闭环）

- **H01 活动首页**：大会视觉区 + 精选轮播 + 参与数据 + 三能力入口
- **H02 创作方式**：经典纪念框 / 智能主题海报 / AI 艺术创作
- **H03 模板列表**：庄重经典 / 智能海报 / AI 国风 / AI 创意 分段筛选
- **H04 模板详情**：3:4 样张、适用提示、AI 提示
- **H05 获取照片**：拍照/相册 + 首次授权弹层
- **H06 照片确认**：质量检测（良好/可继续/阻断三态）
- **H07 生成进度**：按能力分阶段文案、超时提示、失败恢复
- **H08 作品结果**：保存、分享海报、现场精选授权提交
- **H09 精选照片墙**：双列瀑布流 + 拍同款
- **H10 我的纪念**：作品列表、精选状态、空状态
- **H11 说明与授权**：隐私与肖像授权说明
- **H12 活动状态页**：未开始/暂停/结束/链接无效/网络异常（右下角"演示"按钮可切换）

## 状态演示

页面右下角「**演示**」按钮可快速切换演示状态：
- 活动未开始 / 已暂停 / 已结束 / 链接无效 / 网络异常
- 质量检测：可继续（黄色）/ 阻断（红色禁用）
- 生成失败：通用失败 / 内容安全失败

## 红线落实（对照 PRD）

- 大会全称统一为「中国共产党福建省第十二次代表大会」
- 纪念编号 = 「第 N 号纪念档案」+ FJDH 编号，不写"第 N 位代表"
- 不承诺上屏：提交后提示「已提交现场精选」「等待精选」
- 未勾选授权不能提交现场精选
- 照片墙/大屏不显示姓名、微信信息
- 模板、活动文案、统计数字全部**数据驱动**（JS 顶部数据区），不散落硬编码

## 打开方式

直接双击 HTML 文件在浏览器打开即可，无构建步骤、无外部依赖（单文件内联）。
